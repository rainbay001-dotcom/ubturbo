smap 分层内存架构
三层自适应调度 · 透明内存扩展
TIER
L1
本地 DRAM · 热数据层
容量：4 GB · 延迟：~100 ns · 带宽：50+ GB/s
openclaw 热 Tab / JS 引擎 / DOM 树
⇅ 热度感知页面迁移
TIER
L2
UB 借用内存 · 温数据层
容量：动态扩展 · 延迟：<2 ms · 协议：UB RDMA
最近切换的 Tab / 缓存数据 / 网络资源
⇅ 异步预取 + 延迟写回
TIER
L3
NVMe SSD · 冷数据层
容量：TB 级 · 延迟：~100 μs · 协议：NVMe PCIe
历史 Tab / 离线缓存 / 快照数据
